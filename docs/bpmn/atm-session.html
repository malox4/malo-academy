Как пройти за 2 минуты

  1. Клиент вставляет карту. Банкомат проверяет: чиповая / магнитная?
  2. Нет → карта не поддерживается → вернуть карту → конец сессии.
  3. Да → запрос ПИН. Неверный: до 3 попыток, иначе изъятие карты (terminate).
  4. ПИН верный → открыть сессию → клиент выбирает операцию.
  5. XOR, не AND: либо баланс, либо снятие — одна ветка.
  6. Баланс: показать на экране → завершить операцию.
  7. Снятие: сумма → хватает средств? Нет → вернуть карту. Да → процессинг авторизует, система вывода выдаёт наличные и печатает чек.
  8. Успех: завершить операцию → вернуть карту → завершение сессии.

Зачем XOR

В исходной схеме после «Выбрать операцию» стоял параллельный шлюз (AND). Клиент не делает баланс и снятие одновременно — это exclusive gateway.
